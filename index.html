从最底层开始，一步一步把这个主题讲清楚
"城投的资产负债表上，最危险的不是负债，而是那些看起来像资产、但其实不产生任何回报的东西。"
第一章

城投公司到底是什么

城投的商业模式

要理解闲置资产，必须先理解城投公司本身。城投公司（地方政府融资平台）本质上是地方政府的"投资工具"。政府想修路、建桥、搞园区、开发新城，但财政预算不够，于是成立城投公司，以政府信用为背书去借钱，然后用借来的钱做基础设施建设。

这就决定了城投公司的三个根本特征：

  • 投资决策是政府导向的——投什么、投多少，主要由政府规划决定，而不是市场回报决定
  • 资金来源是融资驱动的——自有资金很少，绝大部分靠借债，靠不断滚动融资维持
  • 回报逻辑是间接的——很多项目本身不赚钱（比如免费公路、公园），回报通过土地升值、税收增长等间接方式实现
核心矛盾从这里开始：城投的投资逻辑是"政府导向 + 融资驱动"，而不是"市场需求 + 回报导向"。当这两种逻辑发生冲突时——政府让建的东西市场不需要，或者借来的钱投到了没有回报的项目——产生的结果就是闲置资产。

钱从哪来，到哪去

城投的资金循环可以简化为四步：

第一步
借钱
发债/银行贷款
→
第二步
投资
基建/土地收储
→
第三步
运营
出租/出让/收费
→
第四步
还钱
用收入还本付息

这个循环能正常运转的前提是：第三步产生的收入，足够覆盖第四步的还本付息。如果第三步出了问题——资产建好了但不产生收入——整个循环就断了。借的钱要还，但资产不赚钱，只能靠借新债还旧债。这就是闲置资产问题的起点。

第二章

闲置资产：城投的隐性黑洞

闲置资产是什么

闲置资产是公司账面上记录为资产、但不产生经营收入、不产生现金流、也无法在合理时间内变现的资源。三个关键特征：

  • 账面有价值——确实记在资产负债表上，可能是土地、房产、在建工程、设备、股权
  • 实际无产出——不产生租金、不产生运营收入、不分红、不提供服务
  • 处置有难度——不是今天想卖明天就能卖掉，往往需要数月甚至数年
最可怕的地方：闲置资产不是"不赚钱"这么简单。它在持续消耗现金——利息在算、折旧在提、维护费在花——但没有任何收入来抵补。它是一个"现金黑洞"。

正常资产

产生收入 → 产生现金流 → 覆盖资金成本 → 剩余回报归股东。资产在"工作"。

闲置资产

零收入 → 零现金流 → 但资金成本照样发生 → 净亏损。资产在"睡觉"，但钱还在花。

城投为什么会产生闲置资产

这不是个别管理不善的问题，而是城投的商业模式决定的。根源在四个方面：

根因一：政府指令与市场脱节

城投很多项目不是"市场需要什么就建什么"，而是"政府规划什么就投什么"。当规划与实际需求不匹配时——比如产业园区建了但招商招不满、保障房建了但位置偏远没人租——资产就闲置了。这不是经营失误，而是体制性错配。

根因二：重建设、轻运营

城投的考核长期以"投资完成额"为核心，建好了就算完成任务。但建好之后谁来运营？怎么招商？怎么收租金？这些问题在投资决策时往往没有想清楚。建设是有终点的，运营是没有终点的。很多资产闲置，就是因为"建的时候轰轰烈烈，建完之后无人问津"。

根因三：土地财政的副产品

城投大量收储土地，本意是等土地升值后出让获利。但当房地产市场下行、土地出让遇冷时，这些土地就"砸在手里"了。土地本身不产生收入，但收储时的拆迁补偿、利息支出一分不少。土地财政的盛宴结束时，留下的就是大片闲置土地。

根因四：融资驱动的资产膨胀

城投为了发债融资，需要做大资产规模。于是不断收购、注入各种资产——有些是优质资产，但也有不少是为了凑数而注入的低效资产。资产膨胀了，但运营能力没有同步提升，闲置就产生了。

六种闲置场景

闲置资产不是单一形态。根据资产类型和闲置原因，可以分成六类。它们看起来各不相同，但底层逻辑完全一样：花了钱、占了资源、不产生回报。

闲置土地

成因：收储后遇市场下行，无法出让
城投代政府收储土地，本计划出让获利。房地产下行期土地流拍，地就"趴"在账上。拆迁补偿已付、利息在算，但零收入。最难处置，因为土地价值高度依赖市场周期。

空置房产

成因：位置偏或定价高，出租率低
建好的写字楼、商铺、保障房，因区位不佳、配套不足或定价过高导致出租率低。虽然"闲置"但仍有维护成本——物业、安保、折旧。相对容易盘活，但需要时间。

未运营设施

成因：建成后缺乏运营能力或需求不足
污水处理厂、停车场、产业园等已建成但未投入运营。根因往往是"重建设轻运营"——建的时候没想好谁来管。引入专业运营商后有望改善。

在建停工

成因：资金链断裂、规划变更、政策调整
最危险的一类。已投入大量资金但工程停工，既不能使用也不能产生收入。停工越久报废风险越高。复工需追加投资，不复工就是全部沉没。

低效股权

成因：为做大资产规模而收购的劣质资产
城投为扩张资产规模而参股或控股的子公司，长期亏损不分红。隐蔽性最强——出现在"长期股权投资"科目里，不仔细看以为在"投资"，实际在"烧钱"。

闲置设备

成因：过度采购、技术淘汰、项目变更
采购了但未安装使用的设备，或因技术更新被淘汰的设备。金额通常较小，对整体影响有限。更多反映采购管理的粗放。

危险程度排序

最高危险：在建停工 / 闲置土地

在建停工——已投入巨额资金但完全无法使用，停工越久报废概率越高，减值几乎不可避免。闲置土地——占资量最大，且价值完全依赖市场周期，下行期可能大幅缩水。两者都面临"处置即确认亏损"的困境。

高危险：空置房产

可以通过降价出租或改造来盘活，但维护成本持续发生。部分商业楼宇可能面临结构性空置——不是暂时的，而是永久性的供过于求。

中等危险：未运营设施 / 低效股权

未运营设施——只要找到合适的运营方，有恢复正常运营的可能。低效股权——虽然持续亏损，但可通过股权转让退出。

较低危险：闲置设备

金额小，处置相对简单。更多是管理效率问题，不构成实质性财务风险。

第三章

传导机制：闲置资产如何拖垮一家公司

六层传导链

假设城投花了一笔钱收储了一块地，但迟迟没有出让也没有开发。从这块地"闲置"的那一刻起，一条传导链就开始运转了。这不是理论推演，而是会计准则和市场规律共同决定的必然结果：

第1层
资产入账
总资产虚增
→
第2层
零收入
但资金成本照付
→
第3层
资产减值
利润被侵蚀
→
第4层
现金流为负
靠借新还旧维持
→
第5层
评级下调
融资成本上升
→
第6层
恶性循环
债务雪球

第1层 · 资产入账——总资产虚增

城投花钱收储土地、建设设施、收购股权，这些都记入资产端。资产规模变大了，看起来"更有实力"了。但如果这些资产不产生收入，资产规模的扩大只是虚胖。总资产变大，但有效资产（能产生收入的资产）并没有增加。

第2层 · 零收入但资金成本照付

这是最致命的一层。买地、建楼、收购的钱从哪来？大部分是借的。借钱就要付利息。资产闲置了，收入是零，但利息一分不少。还有维护成本——保安、物业、设备保养——都是现金支出。资产在"睡觉"，但账单在"流汗"。

更隐蔽的是机会成本：这笔钱如果不投在闲置资产上，本可以投到能产生回报的项目里。这部分"本该赚到但没赚到"的钱，虽然不出现在报表上，但实实在在是损失。

第3层 · 资产减值——利润被侵蚀

会计准则要求：当资产的可收回金额低于账面价值时，必须计提减值准备。闲置资产长期不产生现金流，其"可收回金额"很可能低于账面价值。减值损失直接计入利润表，冲减当期利润。

而且减值一旦计提，就不能转回——它是永久性的利润损失。即使公司其他业务在赚钱，闲置资产的减值也可以把利润全部吃掉，甚至导致亏损。

第4层 · 经营现金流为负

利润被减值侵蚀只是"账面"问题，更严重的是现金流。闲置资产不产生现金流入，但维护成本和利息支出是真实的现金流出。经营现金流持续为负意味着公司无法靠自身经营维持运转，必须依靠外部融资——也就是借新债还旧债。

一旦借不到新债，资金链就断了。闲置资产的本质风险不是"亏多少利润"，而是现金流失衡。

第5层 · 评级下调与融资成本上升

评级机构看什么？看资产质量、盈利能力、现金流、债务覆盖能力。闲置资产同时恶化这四个维度。当评级机构发现公司大量资产不产生收益、现金流持续为负、减值风险高时，下调评级几乎是必然的。

评级下调直接导致融资成本上升，利息支出增加，现金流进一步恶化——正反馈循环开始运转。

第6层 · 恶性循环与债务雪球

公司陷入死循环：资产闲置 → 现金流为负 → 靠借债维持 → 债务增加 → 利息增加 → 现金流更差 → 评级再下调 → 融资成本再升 → 需要借更多债……

这个循环会自我加速。每降一级评级，可用的融资工具就少一类，愿意放贷的机构就更少。最终可能到达一个临界点：新借的债连旧债的利息都覆盖不了，那时就是实质性违约。

注意：这个过程不是线性恶化的，而是有一个拐点。在拐点之前，看起来只是"经营困难"；过了拐点，就是"偿债危机"。而闲置资产率，正是判断是否接近拐点的关键指标之一。

三重假象：为什么闲置资产很难被发现

闲置资产最狡猾的地方在于：它让报表看起来比实际更好。这听起来违反直觉——不赚钱的资产怎么会让报表更好看？但仔细分析会计逻辑就会发现，闲置资产至少制造了三重假象：

假象一：资产规模虚增——"大而不强"

闲置资产记在资产负债表上，总资产规模因此变大。但这个"大"是虚的。真正有意义的不是总资产规模，而是有效资产规模——即能产生收入的资产。

为什么危险：银行和投资者经常用"总资产"作为授信和投资的基础指标。如果资产规模是虚增的，那么基于此计算的授信额度、债券发行额度都会被高估——公司借了超出实际承受能力的债。

假象二：资产负债率被低估——"隐性杠杆"

资产负债率 = 总负债 / 总资产。闲置资产计入总资产，使分母变大，负债率看起来更低。但闲置资产不产生收入、难以变现，它实际上不具备"偿还债务"的能力。

真正有意义的指标是有效资产负债率 = 总负债 / 有效资产。这个数字往往比报表上的负债率高得多。一家看起来负债率"安全"的城投，实际杠杆可能已经到了危险区间。闲置资产就像一个隐形的杠杆放大器。

假象三：盈利能力被高估——"利润幻觉"

这个假象出现在减值计提之前。闲置资产在入账初期，只要没有正式计提减值，它就不影响利润表。此时公司的利润看起来正常。但这是延迟确认的损失——闲置资产不产生收入却在消耗现金，这个损失是实实在在的，只是会计准则允许它在减值发生前"暂不确认"。

核心洞察：闲置资产对利润的侵蚀不是"均匀分布"的，而是延迟集中爆发的。在爆发前，利润看起来正常；爆发时，利润断崖式下跌。这种"突然变脸"比缓慢恶化更危险，因为它让投资者和债权人没有时间反应。

三个假象的叠加效应

  • 资产虚大 → 负债率看起来低 → 似乎可以借更多债
  • 利润暂未受冲击 → 评级机构暂时没动手 → 融资渠道暂时畅通
  • 融资畅通 → 继续借钱投入新项目 → 可能产生新的闲置资产
  • 闲置资产继续积累 → 减值风险继续累积 → 拐点越来越近
这就是为什么闲置资产被称为"隐性黑洞"：它不在报表上直接显示为风险，但它在暗中改变了报表数字的真实含义。你以为你在看一家健康的公司，实际上你在看一个经过"会计化妆"的病人。

为什么这个过程很难逆转

理论上，把闲置资产卖掉不就行了吗？现实中远没那么简单：

  • 定价困难——闲置资产没有活跃的交易市场，很难公允定价。卖便宜了是国有资产流失，卖贵了没人买。
  • 程序复杂——国有资产处置需要评估、审批、挂牌、公示，周期动辄数月甚至一年以上。
  • 市场踩踏——当多个城投同时想卖同类资产时，价格会进一步下跌。
  • 账面亏损——如果售价低于账面价值，必须确认处置损失，直接冲击利润。管理层往往不愿意在任期内"暴露"亏损。

所以现实中，很多城投的选择不是"及时处置"，而是"继续持有并祈祷情况好转"。结果就是闲置资产越积越多，风险越来越大。

第四章

闲置资产与融资的关系

前面讲了闲置资产的传导机制，但城投的闲置资产不是抽象的——它往往以具体的项目形态存在。最常见的三种：超高层写字楼、产业园、商业综合体。这三类项目是城投闲置资产的"重灾区"，也是融资困局最集中的体现。

超高层写字楼

超高层写字楼是城投闲置资产中最危险的一种。为什么？因为它同时具备三个致命特征：

  • 投资规模巨大——一栋楼动辄占用城投公司大量资金，占总资产比例很高
  • 建设周期长——建设期间零收入，但资金成本全程在算
  • 空置风险高——二三线城市写字楼供过于求，建好后大量空置是常态

超高层写字楼的融资逻辑是：用未来租金收入覆盖建设期借款的本息。但如果建成后空置率高，租金收入远低于预期，这个逻辑就彻底崩塌。不仅还不清建设期的债，还要继续借钱维持运营——物业、安保、能耗都是现金流出。

一栋空置的超高层写字楼，本质上就是一个巨型闲置资产。它把城投的资金锁死在钢筋混凝土里，既不产生租金，又不好出售（整栋出售极其困难），还持续消耗维护成本和利息。这就是"一栋楼拖垮一个城投"的逻辑。

产业园

产业园是城投最常投的项目类型，也是闲置资产的高发区。产业园的逻辑是：建好厂房和配套设施 → 招商引资引入企业 → 收租金和服务费 → 覆盖投资成本。

问题出在哪？招商。很多产业园在建设时没有做充分的招商前置工作——先建后招，而不是先招后建。结果厂房建好了，但招不到足够的企业入驻，大量厂房和办公楼空置。

产业园相比超高层写字楼有一个优势：可以分期建设。建一部分、招一部分、再建一部分。如果前期招商不理想，可以暂停后续建设，损失相对可控。但如果一次性全部建完再招商，风险就和写字楼一样大。

产业园的核心教训："建设可行性"不等于"运营可行性"。建产业园在工程上没有难度，但能不能招到企业、能不能持续运营，是市场问题，不是工程问题。城投的投资决策往往只论证了前者，忽略了后者。

商业综合体

商业综合体（购物中心 + 写字楼 + 酒店等）是三类项目中融资难度最大的。原因在于：

  • 运营门槛极高——商业综合体的成功高度依赖专业的商业运营能力，而城投通常缺乏这种能力
  • 市场波动敏感——消费市场变化快，定位一旦失误很难调整
  • 退出渠道有限——商业综合体整栋出售极难，REITs 又要求稳定现金流

很多城投建商业综合体时，往往依赖住宅部分的销售回款来反哺商业部分的运营。住宅卖得好，商业亏一点也能撑住。但一旦住宅市场下行，反哺断了，商业部分就成了纯粹的闲置资产——空置率高、运营亏损、卖不掉。

必须避免的陷阱：① 售后返租（卖了商铺再返租统一运营，看似解决了销售问题，实际将风险转移给了散户投资者）；② 过度依赖住宅反哺（住宅和商业的周期高度同步，下行时一起跌）；③ 定位过高（二三线城市建高端商场，市场需求根本撑不起来）。

融资工具与闲置资产的矛盾

城投可用的融资工具很多——专项债、银行贷款、公司债、ABS/ABN、REITs、CMBS 等。但这些工具几乎都有一个共同要求：底层资产能产生稳定的现金流。

这恰恰是闲置资产最缺乏的。所以闲置资产越多的城投，能用的融资工具越少，融资成本越高。这是一个恶性筛选机制：资产质量好的城投，融资工具丰富、成本低；资产质量差的城投，融资工具受限、成本高。

REITs 的误区：很多人认为 REITs 可以解决闲置资产问题。但 REITs 要求底层资产有稳定现金流——闲置资产没有。REITs 是"退出工具"，不是"救活工具"。必须先把闲置资产盘活到能产生稳定现金流的程度，才有可能做 REITs 退出。
第五章

评级冲击：闲置资产如何触发降级

评级机构在五个维度被恶化

信用评级的本质是判断"能不能还钱"。评级机构看的是偿债能力，而闲置资产恰恰从多个维度同时削弱偿债能力：

资产质量

评级机构会分析资产构成，判断哪些是"有效资产"、哪些是"低效/无效资产"。闲置资产率越高，资产质量评分越低。当闲置率超过一定阈值，评级机构可能会将这部分资产从"可偿债资产"中剔除，相当于缩小了偿债安全垫。

盈利能力

闲置资产不产生收入，却通过减值侵蚀利润。ROE 和 ROA 被拉低。如果减值集中爆发，利润可能突然转亏。评级机构特别关注盈利的稳定性和可预测性，而闲置资产带来的减值恰恰是最不可预测的。

现金流

这是评级机构最看重的指标。利润可以"调节"，但现金流很难造假。闲置资产导致经营现金流持续为负或远低于利润，这种"利润与现金流背离"是评级机构重点警惕的信号。

债务覆盖能力

核心指标是 EBITDA / 利息支出（利息保障倍数）。闲置资产拉低 EBITDA，同时公司为了维持运转不得不增加借款，利息支出上升。分子变小、分母变大，保障倍数快速下降。当倍数低于某个水平，意味着连利息都还不起，必须靠借新债付利息——这就是"庞兹融资"的特征。

流动性

闲置资产变现困难，无法在短期内转化为现金。当短期债务到期时，公司可用的流动性主要来自现金储备和可快速变现的资产。闲置资产既不是现金也不好卖，恶化了流动性覆盖。

触发机制与连锁后果

评级不会因为"有闲置资产"就直接下调，而是通过一系列触发事件：

  • 大规模减值——公司集中计提资产减值，导致利润大幅下滑或转亏
  • 现金流持续恶化——连续多个季度经营现金流为负，且没有改善趋势
  • 再融资困难——债券发行失败或利率大幅攀升，市场已经"用脚投票"
  • 审计意见变化——审计师对资产价值出具保留意见
  • 负面舆情——媒体报道闲置资产问题，引发市场关注和质疑
关键理解：评级下调往往不是"渐进式"的，而是"阶跃式"的。在触发事件发生前，评级可能长期不变；一旦触发，可能一次性下调多个子级。这种阶跃式下调会导致融资成本突然大幅上升，加速危机爆发。

评级下调触发一系列实质性连锁反应：

第六章

怎么办：从认知到行动

认知层面：先承认问题

处置闲置资产最大的障碍不是技术问题，而是认知和意愿问题。管理层往往不愿承认资产闲置：

  • 承认闲置 = 承认决策失误——很多闲置资产是前任领导的项目，现任不愿"揭盖子"
  • 处置就确认亏损——卖出价低于账面价值就要确认损失，冲击当期利润
  • 担心国有资产流失——低价出售可能被追究责任，不如"先放着"
  • 寄希望于市场好转——"等房地产市场回暖，地就能卖了"
但现实是：闲置资产不会因为不处置就自动变好。相反，时间越久，减值风险越大、资金成本累计越多、处置难度也越大。"拖"是最差的选择。

操作层面：四层递进

第一层：止血——停止产生新的闲置

在处置存量之前，首先要控制增量：

  • 暂停缺乏明确运营方案的新项目投资
  • 新项目必须进行"运营可行性论证"，不能只论证"建设可行性"
  • 把"资产使用率"纳入投资决策和绩效考核
  • 建立资产全生命周期管理机制，从"建完即交接"变为"建完即运营"

第二层：盘活——让闲置资产"动起来"

对于有盘活可能的资产，优先选择盘活而非出售：

  • 空置房产→ 降价出租、改造为保障性租赁住房、引入专业运营方
  • 未运营设施→ 引入第三方运营商（PPP/委托运营）、调整运营模式
  • 低效股权→ 推动子公司混改、引入战略投资者、股权转让
  • 闲置土地→ 与政府协商变更土地用途、合作开发、政府有偿回收

第三层：处置——卖掉无法盘活的资产

对于确实无法盘活的资产，果断处置，即使要确认损失：

  • 在建停工→ 引入战略投资者接盘、资产打包出售给 AMC、政府接管
  • 闲置土地→ 政府有偿回收（最优先渠道）、土地置换
  • 闲置设备→ 二手市场出售、报废处理
核心原则：处置闲置资产的损失，本质上是确认已经发生的损失，而不是"制造新的损失"。钱在资产闲置的那一刻就已经亏了，只是没有在账面上确认。拖延不处置，只会让损失更大。

第四层：制度——防止问题再次发生

  • 建立资产使用率月报制度——每月统计每项资产的使用/出租/运营情况
  • 将资产运营效率纳入管理层考核——不只看投资完成额，还要看资产使用率
  • 新项目投资决策中增加"运营退出方案"必填项——没有运营方案不批
  • 建立闲置资产预警机制——闲置率超过阈值自动触发评估和处置程序

处置的节奏：越早越好。越早处置，资产状况越好，市场可能还有买家，定价更接近账面价值。越晚处置，资产老化、市场下行、买家更少，损失更大。拖到最后，可能被迫在危机中"甩卖"，甚至无人接盘。

政府的角色：能救什么，救不了什么

城投与政府的特殊关系意味着危机时刻可以获得外部支持，但支持不是无限的：

可以期待政府支持的

闲置土地由政府有偿回收、优质资产注入稀释闲置率、财政补贴覆盖部分减值、协调银行展期降息、推动区域平台整合。

政府也救不了的

闲置规模远超财政承受能力、区域整体信用已受损、闲置资产完全没有市场价值、公司治理问题严重无法执行处置方案。

重要认知：政府支持能"争取时间"，但不能"消除问题"。如果闲置资产的根本原因——投资逻辑与市场逻辑脱节——不解决，即使靠政府支持度过了当前危机，未来还会产生新的闲置资产。外部输血代替不了内部造血。
第七章

实际案例：用底层逻辑看真实城投

前面讲了理论框架，现在用它来分析真实城投公司。以下数据全部来自公开披露的债券募集说明书和年度报告，覆盖五家城投。关键结论：没有一家在报表上直接写"闲置资产"，但用底层逻辑一对照，闲置的痕迹清晰可见。

怎么看：城投报告里"闲置"一词通常只出现在两个地方——①募集资金暂时闲置在做现金管理；②引用《闲置土地处置办法》的合规提示。真正的闲置资产问题不会直接写出来，而是藏在以下几个信号里：存货（土地/开发成本）占比畸高且周转极慢、资产减值损失快速增长、经营现金流长期为负、在建工程长期不转固、投资性房地产公允价值持续下跌。

案例一：潍坊城投——唯一被审计署点名"土地闲置超两年"

闲置土地 · 审计署点名

数据来源：2026 年度第一期中期票据募集说明书 + 2025 年年度报告

潍坊城投是五家城投中唯一在公开报告中明确被审计署指出"土地闲置时间较长，超过两年规定时间"的公司。报告原文还引用了《闲置土地处置办法》中"满四年未动工可无偿收回土地使用权"的规定，并称"闲置土地问题也在逐年解决中"。这是最直接的闲置资产硬证据。

用底层逻辑逐项对照：

  • 根因匹配：土地收储后遇市场下行无法出让——典型的"土地财政副产品"。拆迁补偿已付、利息在算，但土地零收入。
  • 三重假象验证：资产负债率仅约四成多，看起来很安全。但存货中超过五十亿处于抵押或使用权受限状态，货币资金仅二十多亿——报表上的"低杠杆"是假象，真实的资产流动性和偿债能力远弱于报表显示。
  • 融资工具矛盾：土地闲置被审计署点名，直接影响了市场信心和融资条件。受限资产中存货占比最大，说明大量土地已被用于抵押融资——闲置的土地不仅不产生收入，还被押出去借了钱。
  • 利息费用高企：每年利息支出近百亿级别，靠政府补助（其他收益）支撑利润。一旦政府补助减少或融资成本上升，利润立刻转负。
底层逻辑判断：潍坊城投的闲置资产问题已经从"隐性"变为"显性"——被审计署点名意味着问题严重到无法再掩盖。虽然公司声称在"逐年解决"，但土地闲置的根本原因（市场下行导致出让困难）不是公司单方面能解决的。这家公司的处境，就是前面讲的"根因三：土地财政副产品"的真实写照。

案例二：成都城投——存货占近六成，减值三年暴增三百倍

存货沉淀 · 减值暴增

数据来源：2024 年公司债券募集说明书

成都城投的主体评级为 AAA，看起来很健康。但用底层逻辑拆开看，闲置资产的信号非常明显：

  • 存货占比畸高：存货超过一千亿，占总资产近六成。城投的存货主要是土地和开发成本。这么大的存货盘子，如果周转不动，就是闲置资产的温床。
  • 减值暴增——"利润幻觉"正在破裂：资产减值损失从最初约一百万元，暴增至三亿多元。报告明确说"主要为存货减值损失"。这正是第三章讲的"第3层：资产减值——利润被侵蚀"正在发生。存货（土地/开发成本）的可收回金额低于账面价值，被迫计提减值。
  • 多家子公司已注销并全额计提减值：说明这些子公司的资产已经完全没有价值，是闲置资产恶化为不良资产的终局。
  • 经营现金流与利润背离：虽然净利润为正，但经营现金流长期为负或极低——利润看起来在赚钱，但现金在流失。这就是"利润与现金流背离"信号。
  • EBITDA 利息保障倍数极低：前三年的保障倍数都低于一，意味着连利息都覆盖不了，必须靠借新债付利息——庞兹融资特征。
底层逻辑判断：成都城投是"三重假象"的典型案例。AAA 评级 + 一千多亿总资产，表面光鲜。但存货占比近六成 + 减值暴增 + 现金流为负 + 利息保障不足——每一个信号都指向同一个结论：大量资产不产生回报，闲置问题正在从"隐性"走向"显性"。减值暴增就是拐点信号。

案例三：湖州城投——存货占六成，现金流连年大负

资产虚增 · 现金流为负

数据来源：2024 年公司债券募集说明书摘要

湖州城投同样评级 AAA，但财务状况比成都城投更弱：

  • 存货占比更高：存货约八百多亿，占总资产约六成。同样是土地和开发成本沉淀。
  • 经营现金流连续多年大额为负：每年经营现金流净流出数十亿，且没有改善趋势。这就是第四章讲的"第4层：经营现金流为负"——公司无法靠自身经营维持运转。
  • EBITDA 利息保障倍数持续低于一：意味着经营产生的回报连利息都覆盖不了。公司实际在"亏钱运转"，靠不断借债维持。
  • 盈利极弱：净利润极低，ROE 接近零。八百多亿存货不产生收入，但利息和维护成本一分不少——典型的"资产在睡觉，但账单在流汗"。
  • 速动比率极低：扣除存货后，流动资产几乎无法覆盖流动负债。这意味着一旦短期债务集中到期，公司可用的流动性非常紧张。
底层逻辑判断：湖州城投虽然报告里没有"闲置"二字，但它的资产负债结构就是一本闲置资产教科书——存货占比六成、现金流连年大负、利息保障不足、盈利接近零。这些资产记在账上让公司"看起来很大"，但实际不产生任何回报。这就是"假象一：资产规模虚增"的活样本。

案例四：济南城投——在建工程占总资产近一半

在建沉淀 · 最高风险

数据来源：2025 年公司债募集说明书摘要

济南城投的案例最特殊，因为它的闲置资产不是存货（土地），而是在建工程：

  • 在建工程占总资产近一半：在建工程超过一千二百亿，是资产端最大项。这么大的在建工程，意味着海量资金沉淀在"建到一半"的项目里——既不能使用产生收入，也不能轻易处置。
  • 经营现金流曾出现巨额负数：某年经营现金流净流出超过两百亿。这说明公司在那一年大量投入现金到在建项目中，但这些投入短期内不会产生回报。
  • 受限资产增长快：超过两百亿资产处于抵押或受限状态，且在增长。说明公司不断用资产质押去借更多的钱——借新钱养旧项目。
  • 合规风险明确：报告提示"项目用地违反闲置用地规定"——又是一个直接的闲置信号。
  • 速动比率极低：短期偿债能力很弱，大量资金被锁死在在建工程里无法动用。
底层逻辑判断：济南城投是"在建停工/在建沉淀"场景的典型代表。一千二百亿在建工程，是六种闲置场景中最危险的一类——已投入巨额资金但项目尚未完成，既不能产生收入也不能处置。如果这些在建工程长期不转固（转为固定资产开始运营/折旧），就说明项目可能遇到了困难——要么资金跟不上停工了，要么建好了但无法投入运营。报告里明确提到"违反闲置用地规定"，印证了这一判断。

案例五：临沂城投——投资性房地产公允价值连年下跌

低效房产 · 隐蔽信号

数据来源：2026 年度第一期短期融资券募集说明书 + 2025 年年度报告

临沂城投的闲置信号比较隐蔽，体现在投资性房地产上：

  • 投资性房地产公允价值连续下跌：公允价值变动损失连续多年为负，且在扩大。投资性房地产是城投持有的用于出租或升值的房产。公允价值持续下跌意味着市场认为这些房产的价值在缩水——要么出租率低，要么租金下降，要么位置不好。
  • 存货占比约三成：同样存在土地/开发成本沉淀问题，虽然比成都和湖州轻，但仍然不小。
  • 资产减值出现过较大额计提：某年资产减值损失近一亿元，说明部分资产已经确认了价值下降。
  • 政府补助依赖：其他收益（主要是政府补助）对利润支撑很大。扣除政府补助后，自身经营利润很薄。
  • 经营现金流在改善但基础不牢：某年经营现金流转正，但季度又转负，趋势不稳定。
底层逻辑判断：临沂城投的案例展示了一个重要的隐蔽信号——投资性房地产公允价值下跌。这不叫"闲置"，但本质一样：持有房产的目的是出租获利，但公允价值持续下跌说明市场不认可这些房产的收益能力。它不是"闲置"的房产，而是"低效"的房产——可能有部分出租了，但租金覆盖不了资金成本。这是"空置房产"场景的变体。

五家城投横向对比：同一个问题的不同表现

把五家放在一起看，会发现一个清晰的规律：它们面临的是同一个问题——资产不产生回报——但表现形式各不相同：

  • 潍坊城投：土地闲置被审计署直接点名 → 最直接的"闲置土地"场景
  • 成都城投：存货占近六成 + 减值暴增 → "利润幻觉"正在破裂
  • 湖州城投：存货占六成 + 现金流连年大负 → "资产虚增"的活样本
  • 济南城投：在建工程占近一半 → 最危险的"在建停工/沉淀"场景
  • 临沂城投：投资性房地产公允价值连年跌 → 隐蔽的"低效房产"场景
最重要的发现：五家城投中，没有一家的报表上直接写了"闲置资产"四个字。但用底层逻辑一对照——存货占比畸高、在建工程不转固、减值暴增、现金流为负、公允价值下跌——每一家都有明确的闲置信号。这就是为什么前面反复强调：闲置资产是"隐性"的，它不在报表的显眼位置，而是藏在资产结构、现金流和减值的细节里。你不用"底层逻辑"去看，就看不到它。

还有一个共同特征值得注意：这五家城投的盈利都极度依赖政府补助（其他收益）。扣除政府补助后，多数城投的实际经营利润非常微薄甚至为负。这说明它们的资产运营效率普遍低下——大量资产不产生市场化的回报，只能靠政府"输血"维持报表上的盈利。这印证了第六章的结论：外部输血代替不了内部造血。

第八章

常见问题

闲置资产和不良资产是一回事吗？

不完全一样。闲置资产强调"不产生收入"的状态，它可能还没有被正式认定为不良。不良资产通常已经发生了减值或违约。但如果不及时处置，闲置资产会演变为不良资产。可以把闲置资产理解为"准不良资产"——它还没有正式"暴雷"，但暴雷只是时间问题。

为什么不在报表上直接标注"闲置资产"？

因为会计准则没有"闲置资产"这个科目。资产按性质分类（存货、固定资产、在建工程等），不按"是否闲置"分类。要识别闲置资产，需要结合附注信息、资产明细和运营数据来分析。这正是为什么闲置资产是"隐性"的——它不在报表的显眼位置，需要深入分析才能发现。

闲置资产率多少算"危险"？

没有绝对标准，取决于资产类型、公司规模和行业特点。但一般来说：很低的水平属于正常经营波动；中等水平需要关注，说明资产运营效率存在问题；较高水平属于警戒区间，需要启动处置程序；很高水平属于高危，公司可能已经丧失自我修复能力。但更重要的是趋势——闲置率在持续上升，比当前的水平更危险。

闲置资产和"僵尸企业"有什么关系？

当一个城投的资产中大部分是闲置的，且自身无法产生足够的现金流来覆盖债务，它就具有了"僵尸企业"的特征——靠借新还旧维持生存，没有自我造血能力。区别在于，城投背后有政府信用，所以能比普通企业更长时间地维持"僵尸状态"。但这不意味着风险不存在，只是风险被延迟了。

REITs 能解决闲置资产问题吗？

REITs 是盘活闲置资产的有效工具之一，但不是万能药。REITs 要求底层资产有稳定的现金流——这恰恰是闲置资产最缺乏的。REITs 更适合"已运营但效率不高"的资产，而不是"完全闲置"的资产。REITs 是"退出工具"，不是"救活工具"。

普通投资者怎么判断一家城投是否有闲置资产问题？

看以下几个信号：① 总资产很大但营业收入很小（资产周转率极低）；② 经营现金流持续低于净利润甚至为负（利润与现金流背离）；③ 资产减值损失突然大幅增加；④ 在建工程占总资产比例异常高且长期不转固；⑤ 存货（土地）占总资产比例高且周转极慢；⑥ 审计报告中出现"保留意见"或"强调事项段"。如果同时出现多个信号，闲置资产问题的可能性就很大。

闲置资产问题和地方政府隐性债务是什么关系？

两者是一体两面。城投举债建设的资产如果闲置，意味着这笔债务对应的资产不产生回报——债务没有对应的偿债来源。从这个角度看，闲置资产问题越严重，隐性债务的风险就越大。解决闲置资产问题，本质上也是在化解隐性债务风险。

超高层写字楼、产业园、商业综合体，哪个风险最大？

各有各的风险。超高层写字楼——投资规模最大、整栋出售最难、二三线城市空置率最高，一旦空置就是最重的包袱。商业综合体——运营门槛最高、退出渠道最少，最考验运营能力。产业园——相对最可控，因为可以分期建设、分期招商，但如果一次性建完再招商，风险和前两者一样大。共同点是：三类项目的闲置风险，根源都在"重建设轻运营"。
