## 二、企业预警通采集流程（核心）

### 第一步：获取山东城投全量名单

1. 打开 **企业预警通** APP（手机/平板）
2. 进入「债券」→「城投平台大全」
3. 筛选：省份 = **山东省** → 共345个城投平台
4. 重点城市（按债券余额排序）：
   - 青岛（67家，4,902亿）
   - 济南（30家，2,249亿）
   - 潍坊（56家，1,167亿）
   - 烟台、淄博、临沂、威海等

### 第二步：批量下载募集说明书

对每个重点城投公司：
1. 在APP搜索框输入公司名称
2. 进入公司详情页
3. 点击「公告」→「筛选」→ 选择"募集"
4. 找到对应公告，点击PDF图标下载

### 第三步：下载评级报告

在同一公司详情页：
1. 点击「信用数据」
2. 查看历年评级变化（AAA/AA+/AA等）
3. 点击右侧📎图标下载完整评级报告PDF

### 第四步：整理存档

建议按以下结构保存：
```
山东城投/
├── 济南/
│   ├── 济南城市投资集团有限公司/

│   │   ├── 2024年跟踪评级报告.pdf
│   │   └── _announcement_list.json  ← 公告列表备份
│   └── 济南城市建设集团有限公司/
├── 青岛/
│   ├── 青岛城市建设投资(集团)有限责任公司/
│   └── ...
└── 数据汇总.xlsx
```

## 三、Python脚本使用方法

本目录包含以下脚本：

### 3.1 collect_v2.py（非浏览器版）
**功能**：通过上交所API通道批量搜索+下载
```bash
# 安装依赖
pip install urllib3 pdfplumber

# 测试前3家
python collect_v2.py --test

# 指定城市（例：青岛）
python collect_v2.py --city 青岛

# 单个公司（例：济南城投）
python collect_v2.py --company "济南城市投资"

# 查看公司名单
python collect_v2.py --list
```

### 3.2 collect_browser.py（浏览器版）
**功能**：使用Playwright浏览器自动化，支持巨潮资讯+东方财富+上海清算所
```bash
# 安装Playwright（首次）
pip install playwright
playwright install chromium

# 浏览器版搜索（慢但覆盖更多）
python collect_browser.py --test          # 测试3家
python collect_browser.py --city 济南    # 济南所有城投
```

### 3.3 直接下载已知PDF
如果已知PDF的URL，可以直接用：
```bash
python -c "
import urllib.request, ssl, os
ctx = ssl.create_default_context()
ctx.check_hostname = False
ctx.verify_mode = ssl.CERT_NONE
url = 'https://static.sse.com.cn/bond/bridge2/disclosure/announcement/c/202412/052536_20241217_SPZC.pdf'
req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
with urllib.request.urlopen(req, context=ctx, timeout=30) as r:
    open('test.pdf','wb').write(r.read())
print('下载成功')
"
```

## 六、常见问题

**Q: 企业预警通找不到某家公司？**
A: 可能不是发债主体，尝试用公司全称搜索，或在「城投平台大全」中按城市筛选。

**Q: 找不到评级报告PDF？**
A: 评级报告通常在「信用数据」栏目，如果没有PDF下载链接，说明该评级机构未公开全文。

**Q: 上交所/深交所搜不到？**
A: 使用「债券简称」或「债券代码」搜索更精确，不确定时用公司全称+募集说明书组合搜索。

**Q: 如何确认下载的是募集说明书？**
A: 文件名含"募集说明书"、"募集说明书摘要"、"发行公告"字样；页数通常在100页以上。
